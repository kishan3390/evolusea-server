# Seasonal Content & Marketing Campaigns

## Executive Summary

Southeast Asian spiritual markets are deeply tied to religious calendars. Muslim Pro sees **10x traffic spikes during Ramadan** (100K daily installs vs 10K baseline). Thai Buddhist temples see 3-5x attendance during major holy days. This document outlines how to leverage seasonal events—Ramadan, Buddhist holy days, Hindu festivals, Christian holidays—to drive user acquisition, engagement, and retention through targeted content campaigns and time-limited promotions.

## Strategic Importance

### Why Seasonal Campaigns Matter in SEA

1. **Massive Traffic Spikes**
   - **Ramadan (Indonesia):** 30-day period, 100K+ daily app installs for Muslim Pro
   - **Makha Bucha (Thailand):** 2-3x baseline engagement, temple visits surge
   - **Songkran (Thai New Year):** Cultural reset moment, high intent for new habits
   - **Nyepi (Bali):** Day of Silence, captive audience for spiritual apps

2. **Cultural Relevance = Trust**
   - Showing up during holy periods signals cultural understanding
   - Competitor blind spot: Western apps (Calm, Headspace) ignore SEA religious calendars
   - Institutional partnerships: Temples/mosques promote apps that honor their traditions

3. **Monetization Windows**
   - Holy periods = increased willingness to pay (charity, good deeds)
   - Zakat during Ramadan (Islamic giving), merit-making during Buddhist Lent
   - Time-limited premium offers: "Ramadan Special: 30% off for 30 days"

4. **Habit Formation at Scale**
   - Users adopt apps during high-intent periods (Ramadan fasting support, Lent meditation)
   - 30-90 day campaigns = enough time to form habits
   - Post-campaign retention: 2-3x higher than regular acquisition

#### 2. Campaign Content API

**File:** `src/modules/campaigns/application/queries/get-active-campaign.handler.ts`

```typescript
@QueryHandler(GetActiveCampaignQuery)
export class GetActiveCampaignHandler {
  async execute(query: GetActiveCampaignQuery): Promise<CampaignDto | null> {
    const { userId } = query;
    const user = await this.userRepository.findById(userId);
    const today = new Date();
    
    const activeCampaign = await this.campaignRepository.findOne({
      where: {
        active: true,
        startDate: LessThanOrEqual(today),
        endDate: GreaterThanOrEqual(today),
        targetFaith: In([user.faithTradition, 'all']),
        targetRegion: In([user.region, 'global']),
      },
    });
    
    if (!activeCampaign) return null;
    
    const content = await this.getContentForCampaign(activeCampaign.contentIds);
    const offer = activeCampaign.promotionalOfferId 
      ? await this.offerRepository.findById(activeCampaign.promotionalOfferId)
      : null;
    
    return {
      name: activeCampaign.name,
      eventType: activeCampaign.eventType,
      content,
      promotionalOffer: offer,
      daysRemaining: differenceInDays(activeCampaign.endDate, today),
    };
  }
}
```

#### 4. Scheduled Tasks: Campaign Activation

**File:** `src/modules/campaigns/application/cron/campaign-activator.cron.ts`

```typescript
@Injectable()
export class CampaignActivatorCron {
  @Cron('0 0 * * *') // Midnight daily
  async activateCampaigns(): Promise<void> {
    const today = new Date().toISOString().split('T')[0];
    
    // Activate campaigns starting today
    await this.campaignRepository.update(
      { startDate: today, active: false },
      { active: true }
    );
    
    // Deactivate campaigns ending yesterday
    const yesterday = subDays(new Date(), 1).toISOString().split('T')[0];
    await this.campaignRepository.update(
      { endDate: yesterday, active: true },
      { active: false }
    );
    
    // Send campaign launch notifications
    const newCampaigns = await this.campaignRepository.find({ startDate: today });
    for (const campaign of newCampaigns) {
      await this.sendCampaignLaunchNotifications(campaign);
    }
  }
  
  private async sendCampaignLaunchNotifications(campaign: Campaign): Promise<void> {
    const targetUsers = await this.userRepository.findByFaithAndRegion(
      campaign.targetFaith,
      campaign.targetRegion
    );
    
    for (const user of targetUsers) {
      await this.notificationService.send({
        userId: user.id,
        title: `${campaign.name} has begun!`,
        body: 'Explore special content and offers for this holy period.',
        deepLink: '/campaigns',
      });
    }
  }
}
```

## Risk Assessment

### Risk: Campaign Fatigue (Too Many Campaigns)

**Likelihood:** Medium  
**Impact:** Medium (user burnout, notification fatigue)

**Mitigation:**
- Limit to 6-8 campaigns per year (not every minor holy day)
- Prioritize major events: Ramadan, Visakha Bucha, Khao Phansa
- A/B test campaign frequency: Heavy users vs light users

### Risk: Cultural Insensitivity

**Likelihood:** Low (with consultants)  
**Impact:** Very High (brand damage, user churn, backlash)

**Mitigation:**
- Mandatory cultural consultant review for ALL religious content
- Beta test with 50-100 users from target faith/region before full launch
- Feedback loop: "Was this content appropriate?" (post-campaign survey)

### Risk: Low ROI (Effort > Results)

**Likelihood:** Low-Medium  
**Impact:** Medium (wasted budget)

**Mitigation:**
- Start with 2 pilot campaigns (Ramadan, Visakha Bucha) in Year 1
- Measure ROI: (LTV of campaign users - CAC - content costs) / total cost
- Only scale if ROI > 2x

### Risk: Islamic Calendar Date Uncertainty

**Likelihood:** Medium  
**Impact:** Low (launch timing off by 1-2 days)

**Mitigation:**
- Islamic calendar depends on moon sighting (dates not fixed)
- Plan campaigns with 2-3 day buffer (flexible start date)
- Monitor official announcements from Saudi Arabia (Ramadan start)
